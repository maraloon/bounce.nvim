# Bounce.nvim

it's a fork of [original plugin](https://github.com/R1PeR/bounce.nvim) with:
- utf-8 support (you need install `luautf8` lua rock)
- work if you remaped standart `w`/`b` behavior or use plugin, which remap them, f.e. [nvim-spider](https://github.com/chrisgrieser/nvim-spider)
- don't show hints if:
    - it is 1-2 jumps
    - it is begining of line
